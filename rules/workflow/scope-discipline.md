# Scope Discipline

- Only make changes directly related to the current request.
- No unrelated refactors, cleanups, renames, or drive-by fixes unless asked.
- Touching a file for one reason is not permission to tidy the rest of it.
- Several people work in parallel: widening a branch to fix an unrelated file
  buys someone else a rebase conflict.
