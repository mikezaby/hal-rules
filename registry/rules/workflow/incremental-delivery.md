# Incremental Delivery

When a plan has several agreed items, implement ONE at a time. Stop so it can be
reviewed, tested and committed with its tests before the next one starts.

Never batch several items into one uncommitted pile. It makes all of them
untestable, and the whole thing has to be unpicked when one is wrong.
