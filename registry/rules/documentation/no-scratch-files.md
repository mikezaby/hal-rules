# No Scratch Files

Do not create `notes.md`, `TODO.md`, `PLAN.md`, `findings.md` or similar scratch
files in the repository.

The plan or checklist for the current task belongs in the conversation. Anything
worth keeping belongs in a real doc, in its proper place, in the same commit as
the change it describes.
